它不是按顺序跑完一遍，而是每一步看了结果再决定下一步

界面原型，货架和识别过程是模拟的，没有连接真实模型。实际版本里这些判断由你电脑上的 MiniCPM 本地完成。下面是 Agent 在各个界面里的体现。

  1. 你只说要什么，它自己定计划从短信里读出取件码，拆出货架和层，排好先去哪一排
  2. 它告诉你该拍哪里按计划提示下一个货架，而不是让你随便拍
  3. 想 → 做 → 看到 → 再决定拍错货架就不找；两次读数不一致就不采信、重读；看不清就问你
  4. 交付结果，并记得还差什么圈出找到的，没找到的带到下一张照片继续
想它的判断 做调用的工具 看到工具返回的结果 改主意因结果而改变决定 问你把问题交还给你
